# Independent WIN/WDO regime family

Preregistered 2026-09-15 before reading this family's historical economic outcomes.

## Question

Test whether WIN/WDO inverse co-movement has subsequent predictive value, whether it breaks by regime, and whether a model conditioned only on ex-ante observable regime variables robustly improves on a static inverse rule after costs.

## Mandatory evidence

- rolling dependence over multiple long windows;
- lead/lag rather than lag-zero correlation alone;
- conditional dependence and explicit regime-break reporting;
- discovery / untouched validation / untouched historical holdout;
- subsequent-return predictive tests;
- frozen costs before economic survival;
- static inverse benchmark versus one frozen conditioned candidate;
- separate prospective activation only after historical survival.

## Isolation

No H1/H31 modification, no existing counter credit, no causal backfill, no retroactive prospective credit. MT5 is secondary cross-validation only. All safety freezes remain active.
