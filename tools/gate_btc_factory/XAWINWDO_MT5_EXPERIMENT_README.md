# XAWINWDO MT5 primary experiment

This amendment is intentionally scoped to `XAWINWDO_REGIME_001` after explicit user authorization on 2026-09-16.

MT5 is permitted to act as the primary **experimental** source for this family only, subject to fail-closed qualification and coverage checks. This amendment does not admit MT5 as a general Factory source and gives no retroactive scientific, prospective, or backfill credit.

The experiment preserves `RESEARCH_ONLY`, `SHADOW_ONLY`, `NOT_APPROVED`, `ENGINE_FEED=false`, `ORDERS=0`, `REAL_CAPITAL=0`, `NO_RETUNE`, `NO_COUNTER_RESET`, `FAIL_CLOSED`, and leaves H1/H31 untouched.

If the experiment demonstrates adequate auditable coverage, broader official admission of MT5 is a separate source-admission decision.
