# B3 H Next-Generation Research Protocol

Date: 2026-08-23
Status: RESEARCH ONLY

## Non-contamination rule

The active B3 H1 prospective holdout is strictly isolated.

Forbidden inputs for H2-H5 research:
- H1 partial P&L
- H1 partial win rate
- H1 partial expectancy
- H1 partial Sharpe or drawdown
- H1 trade-level winners/losers
- any rule change motivated by current H1 holdout behavior

Allowed inputs:
- historical data strictly before the H1 prospective cutoff
- independently sourced academic / practitioner references
- execution assumptions already frozen before prospective evaluation
- generic infrastructure and data-quality diagnostics that do not expose H1 economics

## Candidate families

H2 — Opening overreaction / mean reversion
- economic thesis: extreme opening moves can partially reverse
- must be conditioned by magnitude and robust after costs
- reject if profitability is isolated to narrow bins or one regime

H3 — Opening/range breakout and volatility expansion
- economic thesis: directional expansion after range resolution
- explicitly treated as high-false-positive family
- reject aggressively if edge disappears at next-bar execution or realistic round-trip cost

H4 — Intraday time-series momentum / continuation across horizons
- economic thesis: own-past-return predictability and persistent directional flow
- test multiple coarse horizons without parameter micro-tuning
- reject if only one exact horizon works

H5 — Regime-conditioned directional model
- economic thesis: momentum/reversal behavior depends on volatility, liquidity and directional regime
- regime variables must be available causally at decision time
- reject if regime filter merely memorizes historical episodes

## Selection funnel

Stage 0 — data integrity
- causal timestamps only
- no leakage
- roll handling frozen
- costs and slippage explicit

Stage 1 — broad historical falsification
- simple rule families only
- coarse parameter grids
- minimum trade count
- net-of-cost evaluation
- stability by year / regime

Stage 2 — walk-forward / untouched historical validation
- no parameter selection on validation fold
- minimum OOS sample
- positive net expectancy
- bounded drawdown
- no dependence on a single month / event cluster

Stage 3 — robustness
- neighboring parameter stability
- delayed execution sensitivity
- higher cost sensitivity
- bootstrap / day-cluster uncertainty
- long/short asymmetry inspection

Stage 4 — prospective eligibility
A candidate may enter prospective tracking only if it passes all prior stages and its rule set is frozen/versioned.

## Promotion policy

Target is not four prospective candidates. Target is 0-2 survivors.

Possible conclusions:
- 0 survivors: correct null result; continue discovery without touching H1
- 1 survivor: freeze and begin independent prospective clock
- 2 survivors: run both prospectively in parallel
- >2 survivors: rank by robustness and economic independence; do not flood the holdout layer

## Practical-market reference

The research process intentionally follows common systematic-futures principles:
- economically interpretable signal families
- multiple horizons rather than single magic parameters
- liquid instruments
- realistic transaction costs and execution lags
- strict out-of-sample validation
- willingness to accept a null result

## H1 isolation invariant

No artifact generated by this work may read, import, parse, summarize or infer current H1 economic outcomes before the original H1 unlock condition is met.
